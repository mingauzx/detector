A proposta

Controle de qualidade com apoio visual

A câmera captura a imagem de uma peça e um sistema de visão computacional pode comparar o que aparece na imagem com um padrão esperado.

01

Detectar componentes

Identificar elementos previstos na montagem e verificar se estão presentes na imagem capturada.

02

Sinalizar possíveis falhas

Destacar áreas para revisão quando um componente não é localizado ou parece estar fora do lugar.

03

Apoiar a equipe

Mostrar um resultado claro para que a equipe de qualidade possa verificar a peça e registrar a ocorrência.

Perguntas frequentes

O que é importante saber?

O site já controla a câmera real?

Não. Este é um protótipo de interface para o TCC. Para controlar ou receber imagens de uma câmera real, seria necessário integrar hardware e software próprios.

Os números são dados reais?

Não. Os contadores, o tempo de análise e o histórico são exemplos simulados para mostrar como o painel poderia funcionar.

Como detectaria uma peça faltando de verdade?

Um sistema real precisaria de imagens representativas, critérios definidos, configuração de câmera e iluminação e testes para medir sua confiabilidade.

O sistema substitui o inspetor?

A proposta é apoiar a equipe. A decisão final e os procedimentos de segurança e qualidade dependem da aplicação industrial.

Aviso acadêmico: esta página simula o conceito de inspeção. Não é software industrial validado nem realiza análise de imagens reais.
